# VNT Remote Android

用安卓手机或平板远程操作电脑，查看桌面、使用键盘鼠标、输入中文，并收听远端声音。

使用前，需要在电脑上安装并启动 [VNT Remote 桌面端](https://github.com/vnt-dev/vnt-remote)，开启远程访问，并准备好电脑地址和访问密码。

## 功能

- 直接连接电脑，或通过 VNT 网络选择同组在线设备。
- 支持触控板、直接触控、外接键鼠、屏幕键盘和组合键。
- 支持中文文本发送、文本剪贴板和远程声音。
- 可调整画质、分辨率和连接协议；支持 H.264、HEVC、AV1，实际可用编码取决于两端设备。
- 保存常用设备与连接配置，支持浅色、深色和跟随系统主题。
- 在“设置”中检查 GitHub Release 正式版更新，查看更新说明并下载适配设备的 APK。

## 下载与安装

需要 **Android 7.0 或更新版本**，目前支持 `arm64-v8a` 和 `x86_64` 两种 64 位架构。

1. 打开 [Releases 下载页面](https://github.com/vnt-dev/vnt-remote-app/releases)，选择需要的版本。
2. 在该版本的 **Assets** 中下载 APK；`SHA256SUMS` 可用于校验文件，`build-info.txt` 记录构建源码版本。临时构建也可从 [安装包构建页面](https://github.com/vnt-dev/vnt-remote-app/actions/workflows/build-apks.yml) 的 **Artifacts** 下载 `VNTRemote-release-…` 压缩包，需解压使用，产物保留 30 天，下载可能需要登录 GitHub。
3. 按下表选择 APK，传到安卓设备后打开安装；如果系统提示，请为下载或文件管理应用开启“允许安装未知应用”。

| 安装包 | 适用设备 |
| --- | --- |
| `VNTRemote-arm64-v8a-release.apk` | 大多数使用 64 位安卓系统的 ARM 手机、平板 |
| `VNTRemote-x86_64-release.apk` | 使用 x86_64 安卓系统的设备或模拟器 |

已安装应用可在“设置 → 检查更新”查询最新正式 Release（不含预发布），发现新版后查看发布说明，并通过浏览器下载对应架构的 APK；没有可用 APK 时可进入发布页面查看。网络不可用或 GitHub 请求受限时可稍后重试。

当前安装包不支持 32 位安卓系统。更新时安装新版 APK 即可；若提示签名冲突，请确认新旧版本来自同一发布来源。

## 开始连接

### 直接连接电脑

适合手机与电脑在同一局域网，或手机能够直接访问电脑地址的情况。

1. 在电脑端开启远程访问，确认地址、端口和访问密码。
2. 打开安卓端的“远程控制”，输入电脑地址，例如 `192.168.1.100:29875`。未填写端口时默认使用 `29875`。
3. 选择与电脑端配置一致的连接协议，输入访问密码并连接。

常用电脑可以添加到“设备列表”，以后直接选择连接。

### 通过 VNT 网络连接

1. 在“服务端”添加 VNT 网络配置，可手动填写，也可使用订阅。
2. 保存并启动该网络配置，确保电脑也已加入同一 VNT 网络。
3. 回到“远程控制”，选择同组在线电脑，输入该电脑的访问密码并连接。

VNT 组网密码用于加入网络，电脑访问密码用于远程控制，两者需要分别填写。“服务端”页面管理的是 VNT 网络连接配置。

## 操作远程电脑

连接后画面自动切换为横屏。可在操作栏切换触控方式、打开键盘或调整画面。

| 操作 | 使用方法 |
| --- | --- |
| 移动鼠标 | “触控板”模式下单指滑动；轻点画面不会点击 |
| 点击与拖动 | 触控板模式使用右下角悬浮鼠标的左右键；按住按键后滑动手指，或用另一根手指滑动画面，可拖动远端光标 |
| 直接操作桌面 | 切换为“直接触控”：轻点点击、滑动拖动、长按右键 |
| 滚动页面 | 默认双指滑动，控制远端滚轮 |
| 缩放或移动画面 | 双指捏合缩放；开启右侧“移动画面”后，双指滑动改为平移本地画面 |
| 恢复完整画面 | 点击“适应窗口” |
| 打开键盘 | 点击“键盘”；点击“开启组合键”后依次选键，再点“发送组合键” |
| 全屏显示 | 点击“全屏”；通过右侧“操作”展开操作栏，点击“退出全屏”或按返回键恢复 |

悬浮鼠标可通过拖动底部调整位置。电脑连接了多个屏幕时，可以切换查看；每次显示一个屏幕。

### 输入中文与复制文本

“发送文本”支持中文：输入文字后点击“发送并粘贴”，文字会写入远端剪贴板并尝试粘贴到电脑当前输入位置。此操作会替换电脑剪贴板中的文本。

获取远端剪贴板前，请先在电脑上复制文本。剪贴板仅在应用位于前台时同步；“仅观看”会话无法操作键鼠或剪贴板。

## 常见问题

**连接不上电脑？**

确认电脑端已开启远程访问，地址、端口、协议和访问密码正确，并检查电脑防火墙是否允许该连接。使用 VNT 时，还需确认两端已加入同一网络且设备在线。

**放大画面后，双指滑动为什么还在滚动电脑页面？**

双指滑动默认发送远端滚轮操作。先开启右侧“移动画面”，即可平移当前放大的画面；关闭后恢复远端滚动。

**切到后台后没有声音，或者连接断开了？**

应用进入后台会暂停本地画面和声音，安卓系统也可能挂起或终止应用。返回前台后会尝试恢复；应用被系统终止时，需要重新连接。

**能用安卓设备作为被控端吗？能传文件吗？**

当前安卓端用于控制电脑，不提供被远程控制功能。暂不支持图片或文件传输、同时连接多台设备，以及多屏同时显示。

**出现本地网络权限提示怎么办？**

请允许本地网络访问，以便连接局域网内的电脑。
